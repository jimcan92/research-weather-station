# Weather Station — Power Supply PCB v3.0

## Architecture: LM2596-5.0 + AMS1117-3.3

```
12-24V DC → PTC 5A → SS34 → 100µF/35V → LM2596-5.0 → +5V rail
                                         │               └→ AMS1117-3.3 → +3.3V rail
                                         │
                                         └→ IRF9540N + 2N7000 MOSFET switch → 12V_SW (wind sensors)
                                         └→ 330k + 100k voltage divider → BAT_ADC
```
